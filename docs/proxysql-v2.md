# ProxySQL admin utilities

The [ProxySQL and ProxySQL admin utilities documentation :octicons-link-external-16:](https://docs.percona.com/proxysql/index.html) provides information on installing and running ProxySQL 1.x.x or ProxySQL 2.x.x with the following ProxySQL admin utilities: 

* The [ProxySQL Admin :octicons-link-external-16:](https://docs.percona.com/proxysql/proxysql-admin-tool-v2-config.html) simplifies the configuration of Percona XtraDB Cluster nodes with ProxySQL.
  
* The [Percona Scheduler Admin :octicons-link-external-16:](https://docs.percona.com/proxysql/psh-overview.html) tool can automatically perform a failover due to node failures, service degradation, or maintenance.
