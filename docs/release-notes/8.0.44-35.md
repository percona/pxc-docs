# Percona XtraDB Cluster 8.0.44-35 (2025-12-)

[Get started with Quickstart Guide for Percona XtraDB Cluster.](../quickstart-overview.md)

Percona XtraDB Cluster is based on Percona Server for MySQL. Percona XtraDB Cluster 8.0.44-35 includes all the features and bug fixes available in Percona Server for MySQL 8.0.44-35. Find a complete list of improvements and bug fixes in the [Percona Server for MySQL 8.0.44-35 (2025-11-27) release notes](https://docs.percona.com/percona-server/8.0/release-notes/8.0.44-35.html).

## Release highlights

Announcement – Discontinuation of the Percona PRO Program

Percona has consolidated its build offerings. The Pro builds are no longer required, and all features have been merged into the main open source Community release.

### MySQL 8.0.44

Improvements and bug fixes provided by Oracle for MySQL 8.0.44 and included in Percona Server for MySQL are the following:

* Fixed an issue where virtual index rollback could fail on 32-bit builds of MySQL Server under certain circumstances. (Bug #38167527)

* Fixed an issue where assertion failures could occur due to data size and bounds mismatches during DDL file operations. (Bug #37882398)

Find the complete list of bug fixes and changes in the [MySQL 8.0.44 Release Notes](https://dev.mysql.com/doc/relnotes/mysql/8.0/en/news-8-0-44.html).

## Improvements

* [PXC-4756](https://perconadev.atlassian.net/browse/PXC-4756): Improved startup behavior during State Snapshot Transfer (SST) when using large InnoDB buffer pools with `innodb_numa_interleave` enabled could delay post-processing long enough to trigger the 300-second SST timeout.

## Bug fixes

* [PXC-4292](https://perconadev.atlassian.net/browse/PXC-4292): Fixed an issue where State Snapshot Transfer (SST) cleanup searched identical directories multiple times when InnoDB paths pointed to the same location.

* [PXC-4682](https://perconadev.atlassian.net/browse/PXC-4682): Fixed an issue where SST/IST progress printed “-nan%” in the MySQL error log; it now correctly displays “0%”.

* [PXC-4709](https://perconadev.atlassian.net/browse/PXC-4709): Fixed an issue where a node could be evicted if `CREATE/ALTER USER` was executed without the `AUTHENTICATION_POLICY_ADMIN` privilege.

* [PXC-4789](https://perconadev.atlassian.net/browse/PXC-4789): Fixed an issue where Data Definition Language (DDL) involving foreign key references caused Metadata Locking (MDL) block–force/block–force (BF-BF) conflicts that could evict nodes from the cluster.

## Packaging and build notes

* Percona XtraDB Cluster 8.0 does not support Debian 13 or Red Hat Enterprise Linux 10.

* Percona XtraDB Cluster 8.0 has ended support for Ubuntu 20.04.
