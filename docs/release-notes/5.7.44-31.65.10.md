# Percona XtraDB Cluster 5.7.44-31.65.10 (2026-03-19)

This release is part of {{post}}. The fixes are available to [MySQL 5.7 Post-EOL Support from Percona customers](https://www.percona.com/post-mysql-5-7-eol-support).

## Release information

The fixes ported to 5.7 are the following:

[`Bug#38208188`](https://github.com/mysql/mysql-server/commit/d338ba09220): Bulk inserts into temporary tables with GIS indexes will inevitably cause crashes.

[`Bug#38573285`](https://github.com/mysql/mysql-server/commit/b56c64b): Queries with thousands of joins spend significant time in `add_table_to_list()` and resolver before failing with `ER_TOO_MANY_TABLES`. Example: 20k-way join parses all 20k tables before error.

[`PS-10391`](https://jira.percona.com/browse/PS-10391): Fixes a memory leak with prefix index on blob columns.
