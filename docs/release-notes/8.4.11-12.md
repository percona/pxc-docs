# Percona XtraDB Cluster 8.4.11-12 (2026-11-12)

Percona XtraDB Cluster (PXC) supports critical business applications in both cloud and on-premises environments, including public, private, and hybrid setups. Our free, open source, enterprise-grade solution includes the high availability and security features your business requires to meet your customer expectations and business goals.

Percona XtraDB Cluster 8.4.12-12 is based on Percona Server for MySQL and includes all improvements and bug fixes available in the [Percona Server for MySQL 8.4.12-12 (2026-11-10) release notes](https://docs.percona.com/percona-server/8.4/release-notes/8.4.12-12.html).

!!! note "A note on MySQL 8.4.12"

    Percona XtraDB Cluster 8.4.12-12 is not based on the MySQL 8.4.12 release. MySQL 8.4.12 is a Critical Security Patch Update (CSPU) — a targeted security release that Oracle can issue between quarterly Critical Patch Updates (CPUs) when needed. The MySQL 8.4.12 CSPU applies to the MySQL Server Docker image only, and its fixes do not affect Percona XtraDB Cluster.

## Bug fixes

The following fix from Percona Server for MySQL 8.4.12-12 is included in this release:

* [PS-11950](https://perconadev.atlassian.net/browse/PS-11950): `mysqldump` did not always dump tables with compressed columns correctly. If a column comment or another quoted string in the table definition contained text that looked like a compressed column attribute, `mysqldump` changed the table definition in the dump, so it was different from the original table. `mysqldump` also did not correctly dump or restore some compression dictionaries, such as dictionaries with names containing quotes, spaces, reserved words or non-ASCII characters, or with non-ASCII data.
