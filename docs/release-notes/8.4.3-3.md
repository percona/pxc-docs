# Percona XtraDB Cluster 8.4.3-3 (2025-01-21)

Percona XtraDB Cluster (PXC) supports critical business applications in your public, private, or hybrid cloud environment. Our free, open source, enterprise-grade solution includes the high availability and security features your business requires to meet your customer expectations and business goals.

## Release highlights

Percona XtraDB Cluster 8.4.3-3 is based on Percona Server for MySQL and includes all improvements and bug fixes available in the [Percona Server for MySQL 8.4.3-3 (2024-12-18) release notes](https://docs.percona.com/percona-server/8.4/release-notes/8.4.3-3.html).

## Bugs fixed

[PXC-4544](https://perconadev.atlassian.net/browse/PXC-4544): Fixed the incorrect error message for `RESET BINARY LOGS AND GTIDS` on a cluster node.

[PXC-4558](https://perconadev.atlassian.net/browse/PXC-4558): MySQL could not connect to `mysql-server` during `post-processing` if the host specified in the `.mylogin.cnf` file was not set to `localhost`.

[PXC-4576](https://perconadev.atlassian.net/browse/PXC-4576): Removed `extra_port` handling in the `wsrep_sst_xtrabackup-v2` SST script.
